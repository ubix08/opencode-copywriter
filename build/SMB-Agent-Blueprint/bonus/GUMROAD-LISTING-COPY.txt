## AI agents aren't just for big tech anymore.

You've heard about AI agents. You know they can automate work. But every guide assumes you have a team of engineers, a $10K/month budget, and six months to deploy.

**The SMB Agent Blueprint is a practical planning tool for small business owners who want to design, scope, and deploy their first AI agent team — without hiring developers.**

### What you get:

**🧩 Agent Role Designer**
- Define agent roles (customer support, lead gen, research, content)
- Set autonomy levels (supervised → fully autonomous)
- Map handoffs between agents

**📋 Scoping Canvas**
- What to automate vs what to keep human
- Cost-benefit analysis for each agent role
- Integration requirements checklist

**🗺️ Deployment Roadmap**
- Phase 1: Quick wins (setup in 1 day)
- Phase 2: Core agents (setup in 1 week)
- Phase 3: Full workforce (setup in 1 month)

**📊 ROI Calculator**
- Hours saved per week per agent
- Cost comparison: agent vs employee vs outsourced
- Break-even timeline

**🎁 Bonus Materials Included**
- Agent Prompt Templates — 10 role prompts ready to customize
- Agent Stack Decision Guide — which tools for which role

### Works for:
✓ SMB owners (1-50 employees)
✓ Solo operators overwhelmed by admin
✓ Freelancers scaling with AI
✓ Micro-agencies wanting automated workflows

### Technical details:
- **Format:** Single HTML file
- **Requirements:** Any modern browser. No installation needed.
- **Works offline:** YES
